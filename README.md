# astrbot_plugin_my_choice (自动好友申请处理)

这是一个为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 编写的插件，允许您的bot**自动处理收到的好友申请**。
该插件支持将好友申请交由LLM处理，依据您设定的人设来决定是否同意该申请。

## 安装方式

在插件市场搜索本插件点击下载，或者
[点按此处](https://github.com/LoreHan64/astrbot_plugin_my_choice/archive/refs/heads/master.zip)
下载文件，在 Astrbot WebUI → 插件 中选择从文件安装。

## 功能特点

* 支持多种处理模式：
  * **自动同意**：无条件同意所有好友申请。
  * **自动拒绝**：无条件拒绝所有好友申请。
  * **依人设自行决定 (聊天模型提示词)**：将包含申请人 QQ 和验证消息的提示词发送给聊天模型，要求其分析并回复 `APPROVE` 或 `REJECT`，从而决定是否同意。
* 转发通知：支持在收到/处理完毕申请后，将消息转发给指定用户。

## 配置项使用说明

安装并启用插件后，在 AstrBot WebUI 的【插件设置】页面，您可以看到以下配置：

1. **好友申请的处理方式**：选择自动同意、自动拒绝还是依据大模型判定。
2. **处理好友申请的聊天模型**：如果您选择了“聊天模型提示词”模式，请在这里选择您想要用作裁决的大模型。留空则默认使用会话当前的默认聊天模型。
3. **传给 LLM 的提示词**：支持修改传递给大模型的提示词。
   - 可用变量：`{user_id}` (申请人)、`{comment}` (验证消息)。
   - *提示*：在聊天模型模式下，请务必在提示词中指示模型在判断时回复 `APPROVE` 或 `REJECT`，以保证正确判定。
4. **消息转发**：这包含三个子选项：
   - **收到申请时是否转发通知**：是否开启消息转发。
   - **转发对象 UMO**：支持通过选择器，指定负责接收通知对象的 UMO（如您个人的 QQ 私聊界面）。
   - **转发消息文本格式**：可自定义转发给您的文本通知样式。
     - 可用变量：`{user_id}`、`{comment}`、`{result}`。

## 注意事项

- 本插件默认只支持基于 AIOCQHTTP 适配器 (OneBot v11) 的平台产生的好友申请（`request.friend`）。
- 为了让模型能够结合“人设”进行判断，请在全局或会话中设定好该模型对应的人格提示词。
